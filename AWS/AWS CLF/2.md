# クラウドへの移行
クラウドを利用すると、初期費用とランニングコストを抑えることができるので、総所有コスト(TCO)が下がる。

## クラウド導入フレームワーク（CAF）
### クラウド導入フレームワーク 6つのパースペクティブ
- ビジネス
- 人材
- ガバナンス
- プラットフォーム
- セキュリティ
- オペレーション

### クラウド導入フレームワーク 4つの利点
- ビジネスリスクの軽減
- 環境、社会、ガバナンスに関するパフォーマンスの向上
- 収益の拡大
- 業務効率の拡大

### AWS Application Migration Service
