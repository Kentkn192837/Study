# 機械学習/深層学習系
## Amazon SageMaker
機械学習するためのモデルやトレーニングを行う環境を提供するサービス。

## Amazon Lex
会話型のAIチャットインターフェースの構築とデプロイを行うサービス<br>
https://aws.amazon.com/jp/blogs/news/amazon-lex-tokyo/
![AmazonLexチャット](./Images/8/lex.png)

## Amazon Kendra
検索システムを構築するためのサービス。検索アルゴリズムには、機械学習や自然言語処理が用いられていることから機械学習系の章に含まれている。
![Kendraメイン画面](./Images/8/kendra.png)

## Amazon Comprehend
文章の感情分析を行うためのサービス。入力された文章がポジティブなのかネガティブなのかといった情報が割合で表示される。
![Comprehendメイン画面](./Images/8/Comprehend.webp)

## Amazon Polly
テキストを音声に変換するサービス。（音声⇒テキスト）
![Pollyメイン画面](./Images/8/polly.png)

## Amazon Rekognition
画像認識や動画の分析を自動化するサービス。
![](./Images/8/)

## Amazon Textract
スキャンされた文書を読み込む光学文字認識(OCR)を提供するサービス。
（画像から文字認識して文字を読み取るなど。）
![](./Images/8/)

## Amazon Transcribe
音声をテキストに変換するAIサービス。（テキスト⇒音声）<br>
Transcribeで文字起こしに使うことができる。（コールセンターで会話の音声を文字に起こすなど）
![](./Images/8/)

## Amazon Translate
翻訳を行うサービス。名前で想像できる通り。

## Amazon Personalize
Amazon Personalizeは、ユーザーのデータをもとに商品や動画などのレコメンデーション（おすすめ）を生成するサービスです。<br>
https://aws.amazon.com/jp/pm/personalize/
