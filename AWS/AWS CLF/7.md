# ファイルストレージ
## Amazon Elastic File System (Amazon EFS) 〇
Linux系OSを利用しているEC2インスタンスや、オンプレミスサーバー間で共有ファイルシステム構築ができるサービス。
複数のEC2インスタンス間で**NFSプロトコル**を用いてファイル共有できる。

## Amazon FSx for Windows File Server
単純にEFSのWindows向けサービスというわけではなく、
Amazon FSx for Windowsファイルサーバーは、Windows Server上に構築されたファイルシステムを提供するストレージサービスです。
SMBプロトコルは主にWindowsコンピュータ間においてファイル共有やプリンタ共有に使用されるプロトコルで、FSx for Windowsでは**SMBプロトコル**が利用されている。

## Amazon FSx for Lustre
LustreはLinuxOS用に設計されたオープンソースのファイルシステムで、主にスーパーコンピューターなどのHPC（High Performance Computing）や機械学習の分野で利用されている。
HPC（High Performance Computing）や機械学習の分野に適したストレージサービスと言える。
